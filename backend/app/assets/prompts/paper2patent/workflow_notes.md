# 论文转专利 · 工作流说明（内容模型与执行顺序）

本文件是模块 B 的横切参考：说明五部分内容模型、text-only 默认格式与 JSON 字段映射。注入生成类调用时用于对齐结构；执行顺序本身不需要模型遵循——已由平台状态机接管。

## 执行顺序（由平台代码执行，仅供理解全局）

原始 skill 的内部执行顺序在本平台映射为流水线阶段，每步由服务端发起独立 LLM 调用或纯代码步骤：

1. 读论文、仅提取有原文支撑的技术内容 → **B2 深读提取**（extraction.md，STRUCT 调用）。
2. 识别区别点、技术问题、技术方案、技术效果 → 同上，四要素闭环入 B2 产物。
3. 选定全文一致的发明名称 → **B3a 权利要求书**调用产出 `invention_name`，服务端逐字一致性校验。
4. 按五大部分结构起草（结构与硬约束以 pro/*.md 为规范源）→ **B3a/B3b/B3c/B3d** 分次生成调用。
5. 论文不支撑的必要内容加 `【待补充：...】` 占位符 → 各生成调用内规则 + B1 gaps 转占位（由平台代码执行）。
6. 跑质量清单并静默修订 → **B4 权项 lint（服务端）+ B4b 忠实性审计 + B7 质检 AUDIT**，补丁由服务端应用。
7. 输出交付物：DOCX/PDF（完整直出）或 text-only 纯文本 → **B5 契约装配 + B6 附图与文件 + B8 交付**（全部由平台代码执行）。

最终稿不得暴露思维链、隐藏分析、自我反思或清单核对结果。

## 五部分内容模型

完整中国发明专利草稿由以下五部分按序组成：

1. 说明书摘要
2. 摘要附图
3. 权利要求书
4. 说明书
5. 说明书附图

该结构同时是 Word/PDF 生成的内容模型。`text-only` 模式的默认最终格式为：

```text
一、说明书摘要
...

二、摘要附图
...

三、权利要求书
1.一种[发明名称]，其特征在于，包括：
...

四、说明书
技术领域
...

五、说明书附图
...
```

## 分节要求

- **说明书摘要**：尽量不超过 300 个汉字；包含名称、领域、核心方案与技术效果；有附图时注明所选摘要附图。
- **摘要附图**：选最能代表核心方法或架构的一幅；没有合适附图时明确写明无摘要附图。
- **权利要求书**：通常 6-10 项；含 1-2 项独立权利要求与有引用基础的从属权利要求。
- **说明书**：含技术领域、技术背景、发明内容、附图说明、具体实施方式。技术背景必须覆盖技术定义、现有方法、现有问题、问题成因与后果；发明内容必须覆盖简要概括、技术方案细化与有原文支撑的技术效果。
- **说明书附图**：给出文字规格，完整文档模式下由平台脚本生成与论文、权利要求书、说明书一致的黑白流程图、系统框图或数据流图。

## 原图优先的附图顺序（附图规格调用遵循；渲染由平台代码执行）

1. 从论文 PDF、截图、图注或架构描述中提取候选原图；
2. 识别有原文支撑的步骤、模块、数据节点、箭头与图的用途；
3. 将原图重绘为整洁的专利参考附图；不得照搬原图的视觉风格、颜色、标题或论文排版痕迹；
4. 生成的专利文本仅用于统一术语、步骤编号、组件标注与图题；
5. 原图与专利文本冲突时，报告材料缺口，禁止编造一个「调和后」的结构。

## 忠实性原则

允许专利式抽象，不允许技术上的发明创造。权利要求可以对论文支撑的步骤作概括上位，但不得增加论文中不存在的新模块、部署环境、硬件限制、应用场景、指标或因果效果。

## 文件生成内容模型（JSON 字段映射）

完整文档生成时，五部分草稿转换为 PatentContent JSON 契约（jsonschema 校验与确定性装配由平台代码执行）。分节标签与字段映射保持稳定，供 DOCX 生成器渲染：

- `abstract` ↔ 说明书摘要
- `abstract_drawing` ↔ 摘要附图
- `claims` ↔ 权利要求书（有序列表）
- `description` ↔ 说明书，含 `technical_field`、`background`、`invention_content`、`drawing_description`、`embodiments`
- `drawings` ↔ 说明书附图规格
- `source_figures` ↔ 论文原图元数据（如有）
- `drawing_assets` ↔ 生成的 SVG/PNG 参考附图元数据
- `image_model_prompts` ↔ Image2 类精修提示词
- `drawing_validation` ↔ 图题污染/留白/线条图检查结果
- `gaps` ↔ 全部遗留占位符与缺失材料
