# 查新 · 检索词构造（Step 5 · STRUCT 调用）

## 任务

平台将用你构造的检索词到「国家知识产权局 中国专利公布公告」站（epub.cnipa.gov.cn）执行检索（服务端爬虫，一次会话多词查询并合并去重）。你的任务：从本案技术方案、专利点与用户主题中构造检索单位。仅输出一个 JSON 围栏块。

## 构造规则（必遵）

   - **拆分责任在你**：从本案技术方案、专利点或用户主题中归纳 **2～8 个与方案相关度高的检索单位**，作为 `blocks` 数组逐项输出。每一单位宜为 **有检索意义的语义块**，例如：**专业术语**、**名词短语**、**名动组合（如「批量调度」「异构调度」）**、**业内固定搭配**；**不要**拆成过碎的单字、泛义双字（如单独 `检索`、`增强`、`系统`、`方法` 等泛词），也**不要**把无关联词硬凑成一串。
   - **禁止**把**无空格的一整句长中文**当作**唯一**检索单位（例如不要仅输出「知识库检索增强大语言模型」这一个块）。长串在公布站单框内易被当作整句 AND，**极易 0 条**。
   - **公布站按字面匹配，不分词、不做同义扩展**：同一概念在专利文献里常有几种写法（如「内窥镜 / 内镜 / 软镜 / 支气管镜」「训练箱 / 模拟训练装置 / 训练模型」），请把最常见的一两种写法都列为检索单位。带修饰语的组合（如「便携式训练箱」「分区式箱体」）只有文献恰好用了同一写法才会命中，宜再配一个去掉修饰语的核心短语。
- **专利类型**：`type_param` 填案件当前专利类型（`invention` / `utility_model` / `design`）即可。检索范围由平台决定：发明、实用新型案件同时检索发明公布与实用新型（两者都构成现有技术），外观设计案件检索外观设计。

## 输出契约（仅输出一个 JSON 围栏块）

```json
{
  "blocks": ["检索单位1", "检索单位2", "…（共 2-8 个）"],
  "type_param": "invention",
  "rationale": "为何选这些检索单位、与本案核心方案的对应关系（1-2 句）"
}
```

服务端校验：`blocks` 数量 2–8；每块须为有检索意义的语义块（专业术语 / 名词短语 / 名动组合 / 业内固定搭配，通常 2–12 字），不得为单字或「系统」「方法」「检索」「增强」类泛词，不得把无关联词硬凑成一串；违规将带错误反馈要求重出。
